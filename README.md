# 4-Bit ALU (Arithmetic Logic Unit) Simulator
A Python-based simulation of low-level computer architecture hardware components with a Tkinter graphical interface.

## Overview
This repository translates hardware-level digital logic into an object-oriented software simulation. Applying concepts from my computer architecture and digital logic coursework, it utilizes modular logic gates (XOR, AND, OR) to construct a functioning ripple-carry 4-bit adder, mimicking the internal processes of a CPU.

## Technical Skills Demonstrated
* **Python:** Object-Oriented structure, array manipulation, and Tkinter UI development.
* **Computer Architecture:** Implementation of full adders, multi-bit binary arithmetic, and state management.
